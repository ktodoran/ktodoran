ParkPro's code is private, so most of my recent work doesn't show up here. Two things that do:

- **[Neon Desk](https://github.com/ktodoran/neon-desk)** — a customer support assistant any company can embed. It answers from the company's own documents, cites what it used, and hands off to a person when it shouldn't answer. Hybrid retrieval on PostgreSQL, intent-based guardrails, an evaluation harness, and an embeddable widget you can [try in the browser](https://ktodoran.github.io/neon-desk/). Still in progress.
- **[Neon Ledger](https://github.com/ktodoran/neon-ledger)** — a double-entry ledger for payment systems in C# and .NET 10. Payments that settle later and can come back, idempotent writes, concurrent payments that queue instead of racing, invariants enforced in PostgreSQL, and a console you can [try in the browser](https://ktodoran.github.io/neon-ledger/). Still in progress.
